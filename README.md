# 계산기 + 테스트코드

이 프로젝트는 입력된 문자열 사칙연산식을  
**검증 → 토큰화 → 계산** 단계로 처리하는 콘솔 계산기입니다.  
JUnit5를 이용해 각 기능을 단위 테스트로 검증하는 것을 목표로 합니다.

---

## 처리 흐름

사용자 입력

ExpressionValidator : 입력값 검증

Tokenizer : 숫자 리스트 + 연산자 리스트로 분리

Calculator : 왼쪽→오른쪽 순차계산

결과 출력

---

## 주요 클래스

### ✔ ExpressionValidator
- null 입력, 공백 입력, 잘못된 문자, 연산자 연속 사용 등을 검사
- **입력값이 유효한지 판별하는 책임**

### ✔ Tokenizer
- `"10 + 20 * 3"` 같은 문자열을
    - numbers: `[10, 20, 3]`
    - operators: `["+", "*"]`
      로 분리
- **수식을 데이터 구조로 변환하는 책임**

### ✔ Tokens
- 숫자 리스트와 연산자 리스트를 담는 DTO 역할

### ✔ Operation / OperationFactory
- + / - / * / / 연산자 문자열을 실제 연산 객체로 매핑
- **확장성을 위한 Factory 패턴 적용**

### ✔ Calculator
- Tokenizer가 만든 tokens를 받아 연산 수행
- **왼쪽부터 순차 계산 정책** 사용  
  (연산자 우선순위 X)

### ✔ Main
- 입력 → 검증 → 토큰화 → 계산 → 출력의 흐름 조립

---

## 테스트 코드 구조



| 테스트 클래스 | 검증 내용 |
|---------------|-----------|
| `ExpressionValidatorTest` | 잘못된 입력에 대한 예외 발생 확인 |
| `TokenizerTest` | 문자열이 올바르게 숫자/연산자로 분리되는지 |
| `CalculatorTest` | 계산 로직이 정상적으로 동작하는지 |
