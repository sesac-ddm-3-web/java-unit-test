## 기능 요구사항

이 계산기는 일반적인 수학적 우선순위가 아닌 **입력 순서**에 따라 계산을 수행합니다.

* **사칙연산 지원**: 덧셈(`+`), 뺄셈(`-`), 곱셈(`*`), 나눗셈(`/`)
* **계산 방식**: 연산자 우선순위를 무시하고 앞에서부터 차례대로 계산
    * 예: `2 + 3 * 4` → `(2 + 3) * 4` = `20`
* **예외 처리**:
    * 입력값이 `null`이거나 빈 공백 문자일 경우 `IllegalArgumentException` 발생
    * 사칙연산 기호가 아닌 문자가 포함된 경우 예외 발생
    * 0으로 나눌 경우 `ArithmeticException` 발생

## 클래스

| **`StringCalculator`** | 계산 흐름을 제어하는 핵심 로직입니다. `Tokenizer`를 주입받아 사용합니다. |

| **`Tokenizer`** | 문자열을 분리하고 검증하는 역할입니다. 정규표현식(`-?\d+`)을 사용해 음수를 포함한 숫자 형식(현재 정수만 가능하도록 했습니다.)을 검증하고, 연산자 유효성은 `Operator`에게 위임합니다. |

| **`Operator` (Enum)** | 연산자 기호와 실제 계산 로직(`BiFunction`)을 매핑하여 관리합니다. 상수별로 기능을 구현하여 `if-else` 분기를 제거했습니다. |

| **`InputView` / `ResultView`** | 사용자의 입력(`System.in`)과 출력(`System.out`)을 담당하는 UI 클래스입니다. 비즈니스 로직과 UI를 격리했습니다. |

## 테스트

* **TokenizerTest**:
    * `@NullAndEmptySource`를 활용하여 `null` 및 빈 문자열 입력 시 방어 로직 검증
    * 정규표현식을 통해 음수(`-5`) 및 잘못된 숫자 형식(`a`, `1.5`, `!`) 검증
    * `@ParameterizedTest`를 활용하여 다양한 예외 케이스를 효율적으로 커버
    * `@Nested 구조`를 사용하여 성공 케이스와 예외 케이스를 그룹으로 묶었습니다.
* **OperatorTest**:
    * 0으로 나누기 시 `ArithmeticException` 발생 여부 검증
    * 올바르지 않은 연산자 기호 입력 시 예외 검증
