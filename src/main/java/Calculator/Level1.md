# 기능 요구사항 정의 
- 사용자는 문자열을 입력한다. 
- 입력한 문자열 값에 따라 사칙 연산을 수행할 수 있는 계산기
- 사칙연산 우선순위를 무시한다.
- 실행결과를 출력할 수 있어야한다. 
---
# 자료구조 및 클래스 정의
### Tokenizer 클래스 정의
- 문자열을 쪼갤수 있는 역할을 담당한다.
- 우선순위가 없으니, 왼쪽에서부터 차례대로 읽으면 되니 큐라는 자료구조를 사용해서 계산한다.

### Calculator 클래스 정의
- 필요한 기능을 Calculator 클래스 안에 정의한다.
- 입출력과 사칙연산기능을 담당한다. 

### Enum 사칙연산 
- 다형성을 위해 Enum 활용 
- 사칙연산을 Enum으로 처리 
- 빈값이거나 사칙연산 기호가 아닐 경우 예외처리
---
# 비즈니스 로직
## Tokenizer 클래스 비즈니스 로직 
### tokenize 함수 
- 문자열을 토큰으로 만든다. 
- 토큰을 큐에 넣는다.
## Calculator 클래스 비즈니스 로직
- 토큰을 담은 큐에서 하나씩 빼서 계산한다.
---
# 예외처리 
- 커스텀예외 CalculatorException으로 통일
- 예외메시지를 Enum으로 관리 
# 테스트 코드 작성
1. Tokenizer의 tokenize 함수가 토큰화을 잘하는지
2. Calculator의 calculate 함수가 계산을 잘 하는지 
3. 예외처리를 하는지 <br>
    3.1 0으로 나누었을때  <br>
    3.2 입력값이 Null이거나 빈 공백 문자일 경우 <br>
    3.3 사칙연산 기호가 아닌 경우  <br>
